How this was run, and caveats
  • Code: main at 823ef5e plus PR 22 (augmentation) and PR 64 (MCP interface) merged into a test branch, plus two patches (orion_runtime.py header handling; check.py augmentor edges).
  • Host: kgb-graph (r7g.large, k3s) in the KGB-CIA account, driven from the laptop with SSM Run Command; files moved through the team S3 bucket.
  • Metadata agents, the first local dry run, and the first two-source run are not in the timeline except the agents' own wall clock; the dry runs found D1 and D2 before the host saw them.
  • Azure figures are the cost lines the augmentation stage prints from its token counts, not an invoice. AWS is from Cost Explorer for the linked account through Nov 12.
  • Peak memory per stage is not shown: the runner reports cumulative child RSS (D10).
